# Stage 09 accessibility

The workspace has a skip link, named navigation, a single shell title, explicit field labels, native buttons and selects, table headers, named overflow regions, and focus-visible indicators. Diagnosis and notification state are described in text. The volume chart has a table of values and a readable empty state. The responsive layouts keep the page width stable while tables scroll inside their own regions.

Chrome checks exercise keyboard focus and viewport behavior with synthetic telemetry. Screen-reader matrix testing and a formal WCAG conformance review remain outside the local verification sample.

Measured static contrast on the workspace palette is 16.49:1 for primary body text, 8.50:1 for secondary text, and 8.56:1 for links. The warning and success badges measure 10.02:1 and 9.82:1 for their foreground and fill. These measurements cover the specified pairs.
