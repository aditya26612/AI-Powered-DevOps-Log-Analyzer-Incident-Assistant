# Workspace design system

The workspace retains the original dark design with high-contrast slate surfaces, restrained borders, a blue navigation accent, and compact operational tables. The default Inter and system stack is retained. Shared controls provide focus indicators, descriptive state labels, charts with tabular alternatives, and a visible stale-data warning.

Amber denotes attention and uncertainty. Confirmed delivery and successful diagnosis use green with text. Text remains the state identifier. Below 590 pixels the navigation becomes a labelled bottom bar, cards stack, and tables scroll inside their own labelled regions.
